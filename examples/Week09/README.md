# Week 9 Notes: Object-Oriented Programming and Classes

Each object has its own unique abilities and expertise.

**State**: an object's data that persists over time.
- Private: limited accessibility
- Public: data accessible by all

Example, a `Flute`:
- Sample calculation: private
- Frequency, gain methods: public

**Classes**: a type that encapsulates and abstracts data and behavior.
- An object is an instance of a class.
- A class can have many instances.

Member variables: data variables encapsulated in an object.

Methods (method functions): functions for accessing and modifying data within objects.

(Reminder to self: look up the three ways to get pitch, online or in the course book.)

Classes are private by default.

Static variable: a particular variable shared and accessible across all instances of the class.

`!=` is the symbol for "different" (not equal).

**Inheritance**: model a new class after an existing one, modifying how it behaves.
