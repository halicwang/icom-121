# Coding Music Fundamentals: Class Examples

This repository holds the working ChucK code from the course I took (Kadenze), organized to match our weekly Canvas schedule. It's here as a fallback: if something breaks during a live class demo, these are real, complete examples you can fall back on. Each week's folder also has its own README, cleaned up from my original course notes for that session.

## Structure

Folders are organized by week, matching Canvas. Inside each, code is grouped by topic the same way it was in the original course.

```
Week01  - Oscillator Exploration
Week02  - Intro to ChucK, Data Types, Time, Control Structures
Week03  - Standard Library, Panning, Arrays
Week04  - SndBuf, Reverse Playback, Modulo
Week05  - Functions, Recursion
Week06  - Unit Generators, Envelopes, Filters
Week08  - Concurrency
Week09  - OOP and Classes
Week10  - Events
```

(Week 7 is the midterm, so there's no code folder for it.)

Open the code in miniAudicle to run it.

## Course

Coding Music Fundamentals (ICOM-121 / ICCC-521), CalArts. Taught by Luisa Pinzon.
